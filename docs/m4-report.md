# M4 学习报告

## 能力
- 云函数 `userCenter` / `action: report`：汇总今日复习、待复习、累计、掌握率、连续天数、近 7 日柱状、回忆质量
- 页面 `pages/report/report`：展示报告；支持下拉刷新与「分享给好友」
- 入口：今日页右上「报告」、我的 →「学习报告」

## 部署
1. `node scripts/install-functions.js`（同步 `common/stats.js`）
2. 重新上传部署 **`userCenter`**（云端安装依赖 / 上传所有文件均可）
3. 开发者工具编译小程序后打开报告页验证

## 说明
- 身份仍只来自 `OPENID`，前端不传 `userId`
- 连续天数按东八区日期；今日若尚未复习，从昨天往前计 streak（今日空档不立刻断）
- 待复习数量来自最近拉取卡片中的到期筛选（上限 100），与「今日」任务同源逻辑
