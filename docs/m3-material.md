# M3：资料上传与基于资料出题

## 功能说明

用户在学习计划 →「资料」页中：

1. 粘贴笔记，或从聊天记录选择 **`pdf` / `txt` / `md`**  
2. PDF：上传云存储 → 云函数用 `pdf-parse` 抽文本 → AI 出卡片  
3. 文本：直接提交正文 → AI 出卡片  
4. 卡片挂到当前计划下，立即可复习  

未配置 AI Key 时，会从段落文本做简易兜底出题。  
扫描版（纯图片）PDF 无法抽字，需换可选中文本的 PDF 或粘贴正文。

## 你需要做的

1. 云开发控制台 → 数据库 → 新建集合 **`materials`**（若已建可跳过）  
2. 执行 `node scripts/install-functions.js`（会安装 `pdf-parse`）  
3. 上传云函数 **`material`**：选 **「上传并部署：所有文件」**（含 `pdf-parse`）  
   - 超时建议 **120 秒**（云开发控制台 → 云函数 → material → 配置）  
   - 内存建议 **1024MB**（大 PDF 下载进内存更稳；512MB 也可能够用）  
   - 单文件上限约 **50MB**；页数不限——云端按 **前/中/后抽页**（约 40 页预算）提取文字，再头中尾抽样送给 AI  
4. 确认云存储已开通（上传 PDF 需要）  
5. 主资料流程拆成两步：先解析落库 → 再 `buildPlan`，降低单次超时概率
